# Hacking

If you want to play around with the sources, or if you want to contribute
to the project, follow the steps described below.

## Prerequisites

You need:

* `uv`
* Python 3.12 or better
* Anki

## Setup

### Virtual Environment

Create a virtual environment:

```sh
uv venv
```

### Install Dependencies

```sh
uv sync --all-groups 
```
